# Правка сайта pomni-m.ru

Статический сайт плюс самодельный инструмент синхронизации по FTP: сравнивает
локальную копию с сервером, показывает расхождения и заливает только изменённое.
Локальная копия лежит в `www/`.

Доступ настроен в `ftp.env` — **этот файл никуда не выкладывать**, там пароль.
В репозитории только шаблон `ftp.env.example`; сам `ftp.env` закрыт `.gitignore`.
Чтобы отобрать доступ, достаточно удалить FTP-пользователя в ISPmanager.

> **Фотографий и видео в репозитории нет.** Каталог шкатулок, кадры из фильмов
> и снимки для сайтов памяти — это съёмка и материалы заказчиков, они не
> выкладываются. Вместо отсутствующего снимка `www/placeholder.js` подставляет
> заглушку с именем файла, поэтому вёрстку и конфигуратор каталога можно
> смотреть как есть. Свои фотографии кладите в `www/` под теми же именами.

## Из чего состоит сайт

| Файл | Что это |
|---|---|
| `www/index.html` | Стартовая: кто мы, миссия и три направления — фильм (красота), сайт (значимость), шкатулка (память) |
| `www/films.html` | Фильмы памяти: карточки, традиционный формат, сравнение, песни памяти |
| `www/sites.html` | Каталог сайтов памяти, превью в рамках, кнопка «Перейти на сайт» |
| `www/catalog.html` | Каталог шкатулок с модификаторами, отзывами и заявкой |
| `www/site.css` | **Общие стили всех страниц**: шапка, подвал, кнопки, модальное окно, форма |
| `www/lead.php` | Приём заявок |
| `www/pamyat/site-*/` | Пять готовых сайтов памяти, каждый — один `index.html` |

Уникальное для страницы лежит в её собственном `<style>`, общее — только в `site.css`.
Правите шапку или подвал — правьте `site.css`, иначе страницы разъедутся.

Кнопки «Смотреть» и «Послушать» на `films.html` берут файл из атрибута
`data-video` / `data-audio`, а не по порядковому номеру — карточки можно
переставлять и добавлять свободно.

## Видео

`compress.py` пережимает 4K с телефона в 1080p. ffmpeg ставится пакетом
`imageio-ffmpeg`, отдельная установка не нужна:

```powershell
& $py -m pip install imageio-ffmpeg
& $py compress.py
```

Таблица `JOBS` в начале файла задаёт, что откуда берётся и нужен ли звук.
**Ролики шкатулок идут без звуковой дорожки** — она вырезается при сжатии
(`-an`), а не просто глушится в разметке.

## Команды

Запускать из этой папки:

```powershell
$py = "C:\Users\user\AppData\Local\Programs\Python\Python313\python.exe"

& $py ftpsync.py diag     # проверить связь по шагам (пароль не показывается)
& $py ftpsync.py ls /www  # посмотреть каталоги на сервере
& $py ftpsync.py pull     # скачать свежую версию сайта в www/
& $py ftpsync.py status   # что изменено локально и что изменилось на сервере
& $py ftpsync.py push     # залить изменения (спросит подтверждение)
```

Если в выводе кракозябры вместо русского — сначала выполнить:

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$env:PYTHONIOENCODING = 'utf-8'
```

## Как откатиться

Перед каждой заливкой `push` кладёт прежние версии файлов в `backups/<дата_время>/`.
Чтобы вернуть старую версию: скопировать файл из бэкапа в `www/` и снова `push`.

## Посмотреть сайт локально перед заливкой

```powershell
& $py preview.py          # http://localhost:8765
```

Обычный `python -m http.server` для этого не годится: он не умеет Range-запросы,
поэтому браузер качает видео целиком и страница подвисает. `preview.py` их умеет.

Чего локальный просмотр **не** покажет: страницы `.php` (нужен PHP), поэтому
форму заявок с каталога проверять надо уже на сервере.

## Каталог шкатулок

Товары, описания и привязка «какой снимок к какому варианту» лежат **в двух местах,
и их надо держать согласованными**:

- `prepare-photos.ps1` — таблица `$map`: из каких снимков с телефона собираются
  файлы для сайта. Запуск пересоберёт картинки:
  ```powershell
  .\prepare-photos.ps1
  ```
- `www/catalog.html` — массив `boxes` в начале скрипта: названия, описания
  и списки файлов для каждого цвета, отделки и гравировки.

Логика показа фото: **выключатели (гравировка, музыкальная) → отделка → цвет**.
Если для выбранного варианта своих снимков нет — например у «музыкальной» их нет
вовсе — показываются снимки предыдущего уровня.

Видео: по одному ролику на товар, `preload="none"` — до нажатия на «плей» не
качается ни байта, вместо кадра стоит первая фотография товара. Ролики сняты в 4K
и весят 4–34 МБ; если появится ffmpeg, их стоит пережать.

Какое видео к какому товару — в блоке копирования в этом README ниже и в массиве
`boxes` (поле `video`). Раскладка сделана по соседству номеров съёмки:

| Товар | Видео |
|---|---|
| Военная | IMG_0193 |
| Классика | IMG_0215 |
| Книжка | IMG_0199 |
| Выдвижная | IMG_0219 |
| Мини | нет |

Неиспользуемые остатки на сервере от прежней раскладки: `knizhka-kozha-1..3.jpg`,
`knizhka-gravirovka-1.jpg` — можно удалить через файловый менеджер панели.

### Отзывы и счётчик заказов

**Сейчас это заглушки.** В массиве `boxes`:

- `orders` — число рядом с «Заказов:». Значения проставлены по вашему указанию
  (военная 108, дальше по убыванию), к реальной статистике не привязаны.
- `reviews` — список подписей. Собирается функцией `placeholderReviews(N)`,
  которая выдаёт «Имя клиента 1…N».
- `REVIEW_TEXT` — один общий текст для всех отзывов.

Чтобы поставить настоящие отзывы, замените `reviews` на массив имён и
перепишите вывод так, чтобы у каждого отзыва был свой текст, например:

```js
reviews: [
  { name: "Сергей П.", text: "…" },
  { name: "Ольга М.",  text: "…" }
]
```

и в `openReviews` брать `who.name` и `who.text` вместо общего `REVIEW_TEXT`.

Снимки с гравировкой «С 23 февраля» (IMG_0226–0230) в каталог намеренно не взяты.

Чтобы свериться, какой исходник что показывает, откройте `фото-шкатулок.html` —
там все снимки с номерами.

## Заявки с формы «Узнать цену»

Форма на `catalog.html` отправляет данные в `lead.php`. Каждая заявка **всегда**
пишется в файл `leads.csv` — он лежит уровнем выше папки сайта, чтобы телефоны
нельзя было скачать из браузера. Даже без настроек ни одна заявка не теряется.

Путь на сервере: `/www/pomni-m-leads/leads.csv`. Забрать его можно так:

```powershell
& $py ftpsync.py ls /www/pomni-m-leads
```

Колонки: дата, имя, телефон, позиция, **модификаторы** (выбранные цвет, отделка,
гравировка), IP, браузер. Файл открывается Excel'ем, кириллица не ломается.

Повторная отправка с одного адреса чаще раза в 20 секунд отклоняется, плюс
в форме есть скрытое поле-ловушка для спам-ботов.

Чтобы заявки ещё и **приходили уведомлением**, надо создать на сервере файл
`lead.config.php` (образец рядом — `lead.config.example.php`) и заполнить в нём
почту либо токен Telegram-бота. Достаточно чего-то одного.

Проверить, что обработчик жив, можно прямо в браузере:
<https://pomni-m.ru/lead.php> — он ответит строчкой JSON с состоянием.

## Что стоит знать про index.html

- Весь сайт — одна страница, CSS внутри `<style>`, скрипты внизу в `<script>`.
- Кнопки «Смотреть» (`.watch`) и «Послушать» (`.order-btn`) привязаны к видео и
  песням **по порядковому номеру** в массивах `videos` и `songs`. Добавите новую
  кнопку с таким классом — сдвинется вся нумерация и кнопки станут открывать
  не те файлы. Для новых блоков лучше вставлять `<video>` прямо в разметку.
- Крупные файлы (больше `MAX_SIZE_MB` из `ftp.env`, по умолчанию 5 МБ) скрипт
  не скачивает — это видео, которые мы всё равно не редактируем. Залить новое
  видео можно: положить его в `www/` и сделать `push`.
